Settings

Updates

Restore all games

Turns CachyPlay off for every game, on every Steam account, and puts their launch options back. Your own options stay.

Uninstall CachyPlay

Restores every game first, then removes CachyPlay's files. Bug reports on your Desktop are never deleted.

Bug reports

A bug report is a zip file with logs and system details that shows why a game or CachyPlay misbehaved. Your home folder, username, Steam IDs, Steam name, hostname and tokens are removed before it's saved.

For a problem with one game, open that game and use its "Save bug report" button instead: the report then includes that game's logs. On GitHub, attach the zip to your issue.
