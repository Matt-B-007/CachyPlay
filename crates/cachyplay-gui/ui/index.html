    Privacy

    CachyPlay works offline. The only things it ever sends: checking GitHub for updates (no personal details), and, if you turn it on below, asking ProtonDB how well a game runs for other players (only the game's number is sent).

    OBS game capture

    Starts games through obs-gamecapture, so OBS's Game Capture source records just the game instead of your whole screen. You can also turn it on for one game in that game's Settings tab.

    Your game settings

    What CachyPlay applies to each game, written as Steam launch options. Paste a line into the game's Properties → Launch options in Steam to keep it without CachyPlay.

      About & self-test

        Restore all games

        Turns CachyPlay off for every game, on every Steam account, and puts their launch options back. Your own options stay.

        Uninstall CachyPlay

        Takes care of every game first, then removes CachyPlay's files. Bug reports on your Desktop are never deleted.

        Bug reports

        A bug report is a zip file with logs and system details that shows why a game or CachyPlay misbehaved. Your home folder, username, Steam IDs, Steam name, hostname and tokens are removed before it's saved.

        For a problem with one game, open that game and use its "Save bug report" button instead: the report then includes that game's logs. On GitHub, attach the zip to your issue.
